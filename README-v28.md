# PresCreator v28 — Distinct Native and AI Reference Themes

- Native theme: editable color, font and per-creator layout system. Works with Native generation and Canva AI guidance.
- AI reference theme: Canva design reference with style notes and optional preview. Works only with Canva AI generation. Never used as a Native slide background.
- Theme Library labels theme types. Older Canva themes are recognized as AI references.
- Slide, E-Invite and Announcement makers preserve all entered details while switching themes.
- Native editing tools and generation are disabled for AI reference themes. Existing Native projects remain unchanged.
- Theme Studio requests multi-slide coordinated reference kits from Canva AI (dependent on Canva API compliance; not guaranteed). Currently only the first returned exported preview is stored.
- No Worker changes. Backend sends text style guidance, not visual image conditioning.
