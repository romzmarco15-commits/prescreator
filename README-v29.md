# PresCreator v29 — Theme Studio controls clarification

- Removed the three misplaced creator navigation shortcuts from the bottom of Theme Studio. Creators remain available in the top tabs/sidebar.
- Theme Studio now displays four color pickers and a heading-font control in both Native and Canva AI modes. In AI mode they act as generation guidance only.
- Kept optional Native presets collapsed unless explicitly opened.
- Removed the duplicate “Save current theme” control from the Library area, which could save a Native theme from the AI workflow by mistake. Native themes are saved using “Save Native theme pack”; AI references are saved from their generated result.
- All Canva and Cloudflare integrations unchanged.
